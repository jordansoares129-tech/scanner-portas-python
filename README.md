# Scanner de Portas em Python

Este projeto é um scanner de portas simples desenvolvido em Python, com finalidade educacional e foco no aprendizado de conceitos básicos de redes e cibersegurança.

## Objetivo

O objetivo do projeto é identificar portas abertas em um host autorizado, utilizando a biblioteca `socket` do Python.

## Tecnologias utilizadas

- Python
- Socket
- Terminal
- Conceitos de redes TCP/IP

## Funcionalidades

- Entrada de IP ou domínio autorizado
- Varredura de portas comuns
- Identificação de portas abertas
- Tratamento simples de conexão
- Execução via terminal
